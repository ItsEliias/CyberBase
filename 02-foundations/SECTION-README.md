# 📚 02 — Foundations

> **A full structured cybersecurity course — start here if you're new.**  
> Covers theory, concepts, and tools before you touch anything practical.

---

## What's in here

Structured course notes from [@MrM8BRH's cyber-security-full-course](https://github.com/MrM8BRH/cyber-security-full-course). Organised into numbered modules so you can work through them in order.

## Modules

| Folder | Topic |
|--------|-------|
| `01-Requirements` | What you need to get started |
| `02-Getting Start` | Environment setup basics |
| `03-Introduction to Cyber Security` | CIA triad, hacker types, threats vs attacks, IDS |
| `04-Netwoking` | IP addressing, subnetting, TCP/UDP, ports & protocols |

## What you'll learn

- The difference between a cyber threat and a cyber attack
- Types of hackers (white/grey/black hat)
- How networking actually works under the hood — IP versions, subnetting, common ports
- What IDS systems do and why they matter
- The CIA triad as a mental model for all security decisions

## Recommended order

Work through folders `01 → 02 → 03 → 04` in sequence. Each builds on the last. After this, head into `../03-thm-notes/pre-security` to put it into practice on TryHackMe.
