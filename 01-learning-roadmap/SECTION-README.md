## How to use it

Open the `README.md` in this folder. Every room is linked directly to TryHackMe. Work through them in order within each category, or jump to whatever skill you're trying to build.

**Tip:** Cross-reference with `../03-thm-notes` as you go — notes for many of these rooms are already in there.
