# 📝 03 — TryHackMe Notes

> **Personal notes from working through TryHackMe's official learning paths.**  
> Organised by path, not by room, so you can follow the progression.

---

## What's in here

Notes taken while completing TryHackMe learning paths, sourced from [@Berkanktk's tryHackMe_notes](https://github.com/Berkanktk/tryHackMe_notes). Covers the major THM paths from beginner through to red team level.

---

## Paths

### `pre-security/`
The starting point. Covers:
- Windows Fundamentals 1, 2, 3
- Linux Fundamentals 1, 2, 3

Good for absolute beginners or anyone who wants to make sure their OS fundamentals are solid before moving on.

---

### `complete-beginner/`
The classic entry path. Covers:
- Introductory Networking
- Nmap
- Network Services 1 & 2
- OWASP Top 10
- Burp Suite basics
- Web fundamentals
- Cryptography
- Shells & Privilege Escalation
- Windows Exploitation Basics
- Basic Computer Exploitation

Work through these in order. Each builds directly on the previous.

---

### `web-fundamentals/`
Focused entirely on web application hacking:
- Web Fundamentals core concepts
- Burp Suite & OWASP Zap
- Common web vulnerabilities (SQLi, XSS, IDOR, etc.)
- Practice machines

---

### `cyber-defense/`
Blue team / SOC focused path:
- Cyber Defense Intro
- Threat & Vulnerability Management
- Security Operations and Monitoring
- Incident Response and Forensics
- Malware Analysis

Essential reading if you're going for a SOC analyst or blue team role.

---

### `red-teaming/`
Advanced offensive content:
- Red Team Fundamentals
- Initial Access techniques
- Network Security Evasion
- Host Evasions
- Compromising Active Directory
- Post Compromise

This path assumes you've done the complete beginner and web fundamentals paths first.
