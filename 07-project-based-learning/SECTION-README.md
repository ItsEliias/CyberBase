# 🔨 07 — Project-Based Learning

> **Learn by building real things — not just following tutorials.**  
> The best way to actually retain skills is to build something from scratch.

---

## What's in here

[@practical-tutorials/project-based-learning](https://github.com/practical-tutorials/project-based-learning) — a massive curated list of project-based tutorials organised by programming language. Instead of passive reading, each entry walks you through building a complete, real application.

---

## Why this is in a cybersecurity repo

Understanding how things are built is what separates a good security person from a great one. You can't effectively break something you don't understand. Building these projects gives you:

- A deep understanding of how web servers, databases, and compilers actually work
- Coding ability to write your own tools, scripts, and exploits
- Experience reading other people's code (critical for code review and CTF challenges)

## Highlights worth noting

- Write an OS from scratch
- Build a shell
- Implement a key-value store
- Write a compiler
- Build a virtual machine

**Python:**
- Build a web scraper
- Create a blockchain
- Write a port scanner
- Build a REST API

**Go:**
- Build a web server
- Implement a load balancer
- Write a CLI tool

**Relevant to security specifically:**
- Linux container in 500 lines of code (C)
- Build a hash table from scratch (C)
- Write your own virtual machine
- Build a web application (multiple languages)

---

## Recommended approach

Pick one project in a language you're comfortable with, then one in a language you want to learn. Don't try to work through the whole list — go deep on a few things rather than shallow on everything.
